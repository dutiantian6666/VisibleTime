# VisibleTime v1.4.1

时间轴可自动与手动缩放，卡片压缩为两行，并让每条连线清楚指向真实时间区段。Windows x64 安装包 **2.10 MB（2,096,005 字节）**，比 v1.4.0 增加 **1,159 字节**。

- 空白日期使用短时间轴，有记录时按卡片密度将全天等比延长；支持“− / 自动 / ＋”调整。
- 时间区段与卡片通过独立曲线连接，使用同色起点圆点、连线和卡片侧边。
- 悬停或键盘聚焦卡片时，其连线和起点突出显示，其他连线淡化。
- 卡片固定两行：时间范围与耗时一行，事项、状态、标签及备注一行；修正和删除位于右侧。
- 长文本省略显示，悬停可查看完整内容，原始备注保留；密集卡片错开时仍保持准确的时间起点。
- 保留 v1.4.0 的顶层提醒、完成耗时门槛、删除保留历史等功能，没有新增运行依赖。

验证通过 36 项 JavaScript 自动测试、10 项原生 SQLite 检查、连续 12 条一分钟密集记录的连线与两行布局、1360/390/320 像素窗口，以及安装后真实 WebView2 缩放、备份恢复和卸载流程。首次静默安装曾返回错误码 2，同一文件重试后全流程通过；首次返回原因未确定。

自动缩放限制单日轴的最大高度，极密集记录通过错开卡片和准确连线展示，也可手动放大。重新打开窗口恢复自动缩放。

升级前从托盘退出旧版，再运行安装包。沿用 `%APPDATA%\VisibleTime\data`，默认卸载保留个人记录。适用于 Windows 10/11 x64、.NET Framework 4.6.2+，依赖系统共享 WebView2；缺少时需联网补装。安装包未做代码签名，休眠验证使用 Windows 电源消息。
