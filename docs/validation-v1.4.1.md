# VisibleTime 1.4.1 交付验证

日期：2026-10-31。记录发布前的安装包验证结果；对应版本见 [GitHub Release](https://github.com/dutiantian6666/VisibleTime/releases/tag/v1.4.1)。

- 安装包：`release/VisibleTime-Setup-1.4.1-x64.exe`
- 大小：2,096,005 字节（2.10 MB），比 1.4.0 增加 1,159 字节。
- SHA-256：`07ebeb9ccf64ee5289da9167d55ac0f229083e84636fdd7a0ee3d058c0be4c1e`

## 本次变化

- 自动缩放全天时间轴：空白日期显示短轴，有记录时按卡片密度等比延长；− / ＋ 可手动调整，点击“自动”恢复。
- 全天时间比例保持一致。密集到仍无法容纳时，卡片顺序错开，每条独立曲线保持准确的时间起点，不共享竖直折线。
- 时间区段、起点圆点、曲线和卡片侧边使用同色。悬停或键盘聚焦卡片时，其曲线和起点置于顶层，其他连线淡化。
- 卡片固定两行：时间范围与耗时一行，事项、状态、标签与备注一行；编辑和删除按钮在右侧。
- 长文本省略显示，悬停可查看完整文本，原始备注和编辑内容不变。

## 验证结果

- Node 自动测试：36 项通过，包含空白日期缩短、密度触发拉长、缩放比例、准确起点和密集卡片不重叠。
- 原生 SQLite 验证：10 项通过。
- 时间流浏览器测试：空白日期、日期切换、手动缩放及恢复、分钟精度、补录与修正、重叠检查、旧秒数保留、实时耗时跨分钟刷新均通过。
- 连续 12 条一分钟记录：卡片无重叠，曲线起点落在对应时间区段内，曲线终点对应卡片中心；悬停时对应曲线与圆点位于最上层。
- 1360、390 和 320 像素窗口宽度：卡片保持两行，无页面横向溢出；长备注保持原文。
- 最终安装包在独立目录完成安装，真实 WebView2 中的缩放和两行卡片验证通过；后台计时、休眠消息暂停、退出重启、备份恢复、删除保留历史及卸载保留无关文件验证通过。
- 打包的全部界面文件与最终源码逐一比较 SHA-256 一致；`git diff --check` 通过。

第一次静默安装返回错误码 2；未发现运行中的 VisibleTime，使用同一安装包重试后，安装、运行和卸载全流程通过，首次返回原因未确定。测试均使用 `desktop-test-data/`，未访问个人数据库。
