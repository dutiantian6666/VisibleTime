# VisibleTime v1.3.0

在轻量桌面版上加入日历、分钟级排程和计划 / 实际对照。Windows x64 安装包约 **2.09 MB**，低于 30 MB 目标。

- 月历浏览、日期选择、添加和修改计划，时间精确到 1 分钟，例如 09:07—09:19。
- 同一天展示计划安排与真实时间足迹；计划重叠时显示提示。
- 从计划一键开始计时，显示累计实际耗时，真实记录仍精确到秒。
- 完成计划可以暂停关联计时；删除计划不会删除已经记录的实际用时。
- 计划与关联信息保存在 SQLite 中，并包含在导出、每日备份和恢复文件中。
- 保留托盘后台计时、休眠暂停、异常退出恢复、秒级时间流补录与修正。
- 直接沿用第一版数据库目录，兼容旧版任务与计时记录。

[下载 Windows x64 安装包](https://github.com/dutiantian6666/VisibleTime/releases/download/v1.3.0/VisibleTime-Setup-1.3.0-x64.exe)

适用于 Windows 10/11 x64、.NET Framework 4.6.2+。小安装包依赖共享的 Microsoft Edge WebView2 Runtime；已有时可离线安装和使用，缺少时安装程序提示联网补装。包含微软官方联网安装引导程序，不包含完整离线运行环境。

升级前从托盘退出正在运行的旧版，并建议导出一份备份。默认卸载保留个人数据，数据库仍在 `%APPDATA%\VisibleTime\data`。

验证覆盖 33 项 JavaScript 核心测试、9 项原生 SQLite 检查、浏览器计时 / 时间流 / 日历流程，以及真实安装后的 WebView2 程序、旧数据库兼容、备份恢复和卸载。

安装包未做代码签名；休眠行为通过 Windows 电源消息测试，未实际进行硬件休眠。当前没有提醒、重复计划和云同步。
