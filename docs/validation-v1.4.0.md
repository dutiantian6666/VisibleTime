## 行为

- 操作提醒使用顶层 popover，并跟随当前弹窗；弹窗关闭时提醒继续显示到原定结束时间。桌面截图：`artifacts/native-toast-v1.4.0.png`。
- 任务累计实际耗时严格大于 60,000 毫秒才允许完成，包含以前日期、多段及当前正在进行的计时。已完成任务可以恢复。
- 删除任务会暂停该任务的活动计时，从专注清单中移除，保留历史耗时、日历计划及备份中的引用。已有计划再次开始计时会恢复任务。
- 时间流按分钟展示全天竖线，已用时间着色，未用时间留白，内容卡片与时间位置连线；密集卡片错开，轴上的时间位置保持原位。
- 补录与修正使用分钟输入；原有秒级数据继续保留，单独编辑备注不改变原始起止时间。

## 通过的验证

- Node 自动测试：35 项通过，包含时间门槛、跨天累计、任务删除、计划恢复和分钟位置。
- 原生 SQLite 测试：10 项通过，包含删除标记保存、备份保留历史和拒绝为已删除任务保存活动计时。
- 专注浏览器流程：计时切换、暂停、严格一分钟边界、完成/恢复、取消/确认删除、刷新保留、跨标签同步、窄窗口、存储异常保护。
- 提醒层级：在打开的数据弹窗中，导出、导入和备份后的提醒命中顶层；关闭记录编辑弹窗后提醒保持显示。
- 时间流浏览器流程：分钟输入、比例位置、午夜结束、密集卡片无重叠、日期切换、刷新、窄窗口、记录删除、旧秒数保留，以及同一墙钟分钟内累计耗时跨过一分钟时的刷新。
- 日历浏览器流程：计划创建/编辑/完成/删除、分钟精度、重叠提示、计划关联计时与窄窗口。
- 最终安装包：独立目录静默安装，真实 WebView2 程序启动与运行、旧 SQLite 兼容、后台计时、休眠消息暂停、退出重启、日历与时间流、备份恢复、任务删除后历史保留，随后卸载并验证无关文件保留。
- `git diff --check` 通过。

桌面测试使用 `desktop-test-data/` 独立数据，不访问用户的个人数据库。首次沙箱内 CDP 连接超时，获准在沙箱外重跑后通过；最终安装包也已重新完成安装验证。

## 现有限制

依赖系统共享的 Microsoft Edge WebView2 Runtime，安装包未做代码签名。密集时间记录的卡片可能延伸至时间轴末尾之后，连线仍指向原时间区段。JSON 数据格式和原有个人数据目录保持兼容。
