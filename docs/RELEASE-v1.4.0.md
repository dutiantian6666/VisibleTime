# VisibleTime v1.4.0

修复弹窗遮挡提醒，增加任务完成耗时门槛、任务删除和全天分钟时间流。Windows x64 安装包 **2.09 MB（2,094,846 字节）**。

- “数据与备份”等窗口内的操作提醒显示在最上层，关闭弹窗后仍能看到尚未消失的提醒。
- 任务累计实际耗时严格大于 1 分钟才允许勾选完成，支持多段与跨天累计；已完成任务可以恢复。
- 新增任务删除按钮，删除时暂停该任务，保留已有时间记录、统计及日历计划。
- 时间流以 00:00—24:00 竖线呈现，已用时间着色，未记录时间留白，内容卡片显示在旁边。
- 时间流显示、补录和修正精确到分钟；已有秒级原始数据继续保留，单独修改备注不改变原始起止时间。
- 沿用轻量原生桌面层和 SQLite，无新增运行依赖，兼容原有个人数据目录。

[下载 Windows x64 安装包](https://github.com/dutiantian6666/VisibleTime/releases/download/v1.4.0/VisibleTime-Setup-1.4.0-x64.exe)

验证通过 35 项 JavaScript 自动测试、10 项原生 SQLite 检查、浏览器流程，以及独立目录中的真实安装、WebView2 运行、旧数据库兼容、备份恢复和卸载保留无关文件。

升级前从托盘退出旧版，再运行安装包。沿用 `%APPDATA%\VisibleTime\data`，默认卸载保留个人记录。适用于 Windows 10/11 x64、.NET Framework 4.6.2+，依赖系统共享 WebView2；缺少时需联网补装。安装包未做代码签名，休眠验证使用 Windows 电源消息。
