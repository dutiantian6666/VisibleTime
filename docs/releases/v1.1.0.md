# VisibleTime v1.1.0 · Windows 桌面版

[下载 Windows x64 安装程序](https://github.com/dutiantian6666/VisibleTime/releases/download/v1.1.0/VisibleTime-Setup-1.1.0-x64.exe)

安装后通过桌面或开始菜单快捷方式启动，无需浏览器或另装 Node.js。

## 这一版完成了什么

- 独立 SQLite 数据库，清理浏览器记录不会删除桌面版数据。
- 关闭窗口留在系统托盘，后台继续计时。
- 托盘提供重新打开、暂停计时、退出并暂停功能。
- 休眠自动暂停，唤醒不自动续计；异常退出后恢复到最后保存时刻并暂停。
- 每日及正常退出自动备份，支持立即备份和手动导出。
- 导入旧版数据或恢复备份前，自动备份现有记录，并要求确认替换。

## 迁移旧版数据

在原浏览器、原地址打开当前版本附带的网页版，刷新后通过“数据与备份”导出 JSON；再到桌面版中导入。第一版记录仍存在时才能迁移，桌面版不会自动读取其他浏览器。

数据目录：`%APPDATA%\VisibleTime\data\`。升级会保留该目录。任务记录和数据库不会上传到 GitHub。

## 验证范围

- 18 项核心和数据库测试。
- 网页回归与导出测试。
- Electron 集成测试：清理网页存储后数据保留、关闭隐藏、休眠事件暂停、退出保存、重新启动、导入导出和备份。
- 对打包后的 EXE 执行同一组集成测试。

休眠通过模拟系统事件验证，未实际让开发电脑休眠。当前安装包未做代码签名。附件 `SHA256SUMS.txt` 提供安装包 SHA-256 校验值。

本版对应桌面存储阶段；时间流和日历将在后续版本发布。`v1.0.0` 保持不变。
