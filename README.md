# VisibleTime · 看见时间

一个自己用的时间管理工具：任务清单、专注计时和今日统计。无需安装第三方依赖，不需要账号或后端数据库。

## 启动

Windows 双击 `start.cmd`，保留启动窗口，然后在浏览器打开：

http://127.0.0.1:4173

也可以在项目目录运行 `node server.mjs`。请通过本地服务访问，直接双击 HTML 不支持模块加载。

## 使用

- 输入任务名称，按 Enter 或点击加号添加。
- 点击任务右侧的播放按钮开始计时；开始另一项任务时，前一项会自动停止并保存。
- 点击暂停结束本段计时，再次开始同一任务会累加到今日用时。
- 点击任务左侧圆圈完成任务。正在进行的任务会先自动停止；在“已完成”中可以恢复任务。
- 下方展示今日总投入、与今天有交集的专注次数、今日完成数和各任务耗时。完成后恢复的任务不计入今日完成数。
- 待办包含此前尚未完成的任务，任务右侧的耗时只统计今天。

计时依据实际开始、结束时间计算，不依赖页面每秒刷新的次数。刷新、切换标签页或关闭浏览器后，未暂停的计时仍继续；重新打开时恢复显示。关机、休眠期间也会计入未暂停的计时，离开前请手动暂停。

“今天”按设备的本地时区确定，跨午夜的时间记录分别计入各天。跨天的一次专注在每个有投入的日期各计为一次；更早的记录保留，第一版只展示今日统计。

## 数据保存

数据保存在当前浏览器当前地址的 `localStorage`，键为 `visible-time.v1`。同一地址的多个标签页会同步变化。保存失败时提示并暂停写入，避免误以为操作已经保存；原始数据无法解析时不覆盖原始记录。

请固定使用相同的地址、端口和浏览器。`localhost` 与 `127.0.0.1`、不同端口、不同浏览器各自使用独立存储。清理网站数据或退出隐私浏览可能使记录丢失。第一版没有云同步和备份导出。

## 验证

运行 `node --test tests/core.test.mjs`，验证任务切换、暂停累加、刷新恢复、完成任务、跨午夜统计和无效数据保护。

项目使用原生 HTML、CSS、JavaScript 和 Node.js 内置静态文件服务，不需要构建。
