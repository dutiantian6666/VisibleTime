# VisibleTime · 看见时间

个人时间管理工具：任务清单、专注计时和今日统计。

当前版本 **1.4.0**，提供轻量 Windows 桌面版、独立本地数据库、系统托盘、备份恢复、全天时间流和分钟级日历。安装包约 **2.09 MB**，发布门槛为 **30 MB（30,000,000 字节）以内**，没有新增运行依赖。

## 下载与安装

- [下载 1.4.0 Windows x64 安装程序](https://github.com/dutiantian6666/VisibleTime/releases/download/v1.4.0/VisibleTime-Setup-1.4.0-x64.exe)
- [v1.4.0 版本说明与校验文件](https://github.com/dutiantian6666/VisibleTime/releases/tag/v1.4.0)
- [所有历史版本](https://github.com/dutiantian6666/VisibleTime/releases)

运行安装程序，按向导安装。通过桌面或开始菜单的 VisibleTime 快捷方式启动，无需安装 Node.js 或单独启动服务。当前支持 Windows 10/11 x64、.NET Framework 4.6.2 及以上版本，安装包未做代码签名。

从 1.2.0 起，桌面层使用 Windows Forms + 系统共享的 Microsoft Edge WebView2 Runtime，不再随安装包携带 Electron/Chromium。已有 WebView2 时可离线安装和使用；缺少时，安装程序提示联网补装微软官方运行环境。安装包包含官方引导程序，**不包含完整的离线 WebView2 运行环境**。共享运行环境及首次运行生成的缓存不计入安装包体积。

升级前从托盘退出旧版。1.1.0 的 Electron 程序可以先卸载，再安装轻量版；默认卸载保留个人数据。轻量版安装在 `VisibleTime-Light` 目录，直接使用相同的数据库，避免把旧版运行环境残留计入新版安装目录。

## 桌面版使用

- 输入任务名称，按 Enter 或点击加号添加。
- 点击任务右侧播放按钮开始计时；切换任务时自动停止并保存上一段。
- 点击暂停结束本段计时；再次开始同一任务会累计今日耗时。
- 累计实际耗时严格大于 1 分钟后，才能点击左侧圆圈完成任务；支持跨天、多段累计。无耗时、不足 1 分钟和刚好 1 分钟时不可勾选；已完成任务仍可恢复。
- 点击任务右侧 × 删除任务。删除会暂停该任务正在进行的计时，保留已有时间记录、耗时统计及日历计划；从保留计划再次开始计时会恢复任务。
- 关闭窗口会隐藏到系统托盘，**后台继续计时**。点击托盘图标重新打开窗口。
- 需要结束程序时，右键托盘选择“退出并暂停计时”，或在“数据与备份”中退出。
- 电脑休眠时自动暂停；唤醒后由你手动开始下一段。系统会话结束时也会尽力保存并暂停。
- 如果断电或异常终止，重新启动时将上一次计时恢复到最后心跳时刻并暂停，正常保存时可能少记最多约 5 秒；以实际最后成功保存的心跳为准。

耗时根据开始和结束时间计算，不依赖页面刷新的次数。待办包含以前尚未完成的任务，右侧耗时和下方统计只显示今天。跨午夜记录按设备本地时区拆分。

## 时间流

切换到“时间流”，一天以 00:00—24:00 的竖线呈现。着色区段对应实际占用时间，未记录的时间保持留白。事项、起止时间、耗时、备注及操作放在旁边的卡片中，密集卡片自动错开，并以连线对应原有时间位置。

支持日期与事项筛选、手动补录、备注、修正和删除。时间显示、补录与修正按分钟，不足 1 分钟的记录单独标注。已有计时的原始秒数仍保留，单独修改备注不会改变起止时间，修正保留最初的起止时间。

实际记录不能位于未来，也不能与其他记录重叠。进行中的记录需要先暂停再修正或删除。跨午夜的记录在每天只计算与当天重合的部分。

## 日历与计划

切换到“日历”，按月浏览并选择日期，点击“添加计划”设置事项、起止时间和备注。时间可精确到 **1 分钟**，例如 `09:07—09:19`，不要求按 15 或 30 分钟对齐。计划可以跨日，也可以重叠，重叠计划会显示提示。

选中日期后，可同时查看“计划安排”和“实际足迹”。点击计划中的“开始计时”，从点击时刻开始记录真实投入，计划中显示该计划的累计实际耗时；不会把计划时间自动当作已完成时间。开始已有完成任务的计划时会恢复该任务。

“标记完成”只改变这项计划的状态；如果该计划正在计时，会先暂停。删除计划保留实际记录，解除它与计划的关联。时间流中将实际记录改到其他事项时，也会解除原计划关联，避免错误累计。日历计划和关联信息会随 SQLite、JSON 导出及备份一起保存。

当前没有重复计划、提醒、拖拽排程或云同步，全部数据仍在本机。

## 数据保存与备份

桌面版数据固定保存在：

```text
%APPDATA%\VisibleTime\data\
  visible-time.db
  backups\
```

清理浏览器历史、Cookie 或网站数据不会删除这里的数据库。升级安装会沿用该目录，默认卸载不删除个人记录。软件代码上传 GitHub，个人数据库和备份文件不会上传。

右上角“数据与备份”提供：

- **导出全部数据**：生成 JSON 文件，可保存到其他磁盘。
- **导入数据 / 恢复备份**：先验证文件，再确认替换；替换前自动保存原有数据。
- **立即创建本地备份**：保存当前数据快照。
- **打开数据文件夹**：查看数据库和备份。

操作结果提醒显示在弹窗及模糊背景上方；关闭弹窗后仍能看到尚未消失的提醒。

软件启动和运行期间会检查每日备份，正常退出也会备份。本机自动备份与原数据库在同一磁盘，建议定期导出一份到其他位置。

正在运行的计时会在导出文件中保留原始开始时间；导入时停止在文件的导出时刻，避免累计传输和等待期间的时间。也支持直接导入 v1 格式的原始数据。

## 从第一版网页版迁移

1. 在原来使用的浏览器中，通过原地址打开当前项目的网页版，通常为 `http://127.0.0.1:4173`；刷新后可看到“数据与备份”按钮。
2. 选择“数据与备份 → 导出全部数据”，保留生成的 JSON 文件。
3. 打开桌面版，选择“数据与备份 → 导入数据 / 恢复备份”，选中该文件。
4. 确认导入，核对任务和累计用时。

迁移必须在原浏览器、原地址和原端口进行。桌面版不会自动读取其他浏览器的数据。已经被清理的第一版浏览器记录无法凭空恢复。

## 开发与测试

使用 Windows 10/11 x64、系统 .NET Framework C# 编译器、Node.js 24.22 或兼容版本、pnpm 11.25。NSIS 3 可安装到 PATH；构建脚本也支持已有 electron-builder 的 NSIS 缓存。

```powershell
pnpm desktop
```

网页兼容模式：双击 `start.cmd`，或运行 `node server.mjs`，访问 `http://127.0.0.1:4173`。网页版仍使用浏览器存储。

```powershell
node --test tests/*.test.mjs
pnpm run test:native
pnpm run build:win
```

首次构建从微软 NuGet 源下载固定版本的 WebView2 SDK，验证 SHA-256；官方 WebView2 引导程序验证微软数字签名。仅复制界面文件、必要 SDK DLL 和应用程序，不收录开发依赖。安装包超过 30,000,000 字节时构建失败。

安装包输出在 `release/`，不会提交到 Git。安装程序作为对应 GitHub Release 的附件保存。`desktop:electron` 和 `build:electron` 保留旧架构的开发入口，需要原有 pnpm 依赖；默认构建使用轻量版。

可选浏览器和桌面集成测试依赖 Playwright，支持通过 `PLAYWRIGHT_MODULE` 指定已有安装的绝对路径：

```powershell
node tests/browser.mjs
node tests/history-browser.mjs
node tests/calendar-browser.mjs
node tests/native-desktop.mjs
```

桌面测试使用独立的 `desktop-test-data/` 目录，不接触真实个人数据。休眠测试向测试窗口发送 Windows 电源消息，未实际让开发电脑休眠。通过 `VISIBLE_TIME_EXECUTABLE` 可指定安装后的 EXE 进行相同验证。远程调试和测试控制仅在 `VISIBLE_TIME_TEST=1` 时启用。

`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-native-install.ps1` 在独立目录中安装，测试安装后的程序，再卸载并验证无关文件保留。安装测试使用 `/TEST`，不修改快捷方式和安装注册项。
